Answer-1. DevOps (Development + Operations) is a way of working where developers and operations teams collaborate closely to build, test, and release software faster and more reliably.
In traditional processes, the development team writes the code and the operations team handles deployment separately. This separation often leads to:
More production-level bugs, Miscommunication between teams and Slower releases. 

DevOps addresses these issues with Automation, CI/CD, Shared responsibility across teams.

Answer-3. Continuous Integration (CI) includes pushing code to a repo, automatically building the application, and running tests to ensure everything works correctly. 

Continuous Deployment (CD), on the other hand, involves deploying the tested application and making it available for use. The “D” can also stand for Continuous Delivery, which means the application is ready for deployment but may require manual intervention, such as an approval step, before releasing it to production.
